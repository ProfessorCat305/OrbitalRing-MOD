# 联机与多语言维护

## 联机原则

联机双方应使用相同的游戏版本、模组版本和影响玩法的配置。适配沿用 Nebula 的建筑操作与工厂传输，在这些入口之外补传星环自己的状态。

相同输入可以推导的生产、自动搬运和运行结果仍由各端计算。允许不影响正常游玩的短暂库存或显示偏差，不做逐帧校准。新增联机功能时，先区分玩家操作、载入所需的额外状态和日常计算；只有前两类需要额外数据包。随机科技结果等无法保证各端独立得到相同结果的持久状态，由主机确认后发送。

| 变化 | 处理方式 | 主要入口 |
| --- | --- | --- |
| 玩家加入 | 游戏就绪后请求一次全局状态，包括额外科技效果、恒星光度、星门和数学率引擎记录 | `MultiplayerSync` |
| 载入星球 | 在原有星球包后附加星环、共享空间、制造台插件、温室堆叠关系和无尽水罐记录；工厂载入完成后导入 | `MutliPlayerPacket`、`AssemblerModuleNetwork` |
| 打开共享空间窗口 | 请求所在星球的最新附加快照 | `UIOrbitalRingStorageWindow.OpenWindow` |
| 装卸插件、主动存入乾坤物品 | 发起端预留物品，主机确认实际接收量，仅向操作者返还剩余物；另行广播建筑或库存状态 | `MultiplayerTransfers` |
| 修改共享开关或储量上限 | 发送目标值，主机转发；接收端直接应用，不再次发送 | `MultiplayerStorage` |
| 修改生态温室配方 | 发送联动操作；远端更新配方时不向本地玩家返还原料 | `SyncFarmAssemblerRecipes`、`SyncFarmRecipesProcessor` |
| 原有巨型制造台、星球特质等操作包 | 主机转发给其余玩家，并抑制原版建筑操作重放时的再次发送 | `MutliPlayerPacket` |

玩家背包只在操作发起端扣除或接收回执，状态广播本身不能生成玩家物品。由 Nebula 重放的拆除操作按包作者返还插件，不能使用主机玩家的背包。收到重复回执时不再次发物品。会话结束会清理请求和载入缓存；尚未收到回执的物品不自动退款，以免已入库的物品被复制，因此操作提交期间断线仍可能丢失未确认的返还。

磁盘存档保持原布局。网络格式变化时递增 `MultiplayerSync.ProtocolVersion`；该值附加到 Nebula 握手版本，双方必须一致。星球快照只替换目标星球的星环与插件；其中温室堆叠关系和无尽水罐记录复用现有全局导出格式。

## 多语言词表

当前游戏开放的语言为下列五种；判断范围以游戏 `Locale/Header.txt` 中已开放的条目为准。

所有译文统一存放在 `data/strings.json`，每条记录包含 `Name` 和以下五个非空语言字段。

| 语言 | LCID | 字段 |
| --- | --- | --- |
| 简体中文 | 2052 | `ZHCN` |
| English | 1033 | `ENUS` |
| Français | 1036 | `FRFR` |
| Deutsch | 1031 | `DEDE` |
| 日本語 | 1041 | `JAJP` |

`TranslateUtils` 读取这一份词表，将五种语言注册到 CommonAPI，并按当前游戏语言返回译文；未知键沿用原有行为，直接返回输入。自建界面沿用现有的 `TranslateFromJson()` 调用方式。

维护词表时必须同时更新五种语言，保留格式占位符、富文本标签、游戏数值与操作条件。翻译修正包含既有译文的含义、数值和富文本格式问题。新增键直接加入同一份词表，不拆分语言文件。完成后静态核对键是否重复、五种语言字段、占位符与富文本结构。

补译任务只修改词表和支持所需语言的现有翻译入口。未明确要求时，不增加界面自动刷新、翻译绑定或新的加载层。提交前逐项核对差异是否直接服务于用户要求；范围外问题只记录位置、证据和影响，列入交付说明的“新发现问题”，不顺手修改。

移除条目前，必须核对有效 C# 字面引用、原型 JSON、动态拼接和原版游戏直接读取的键。注释中的旧界面不能单独作为保留依据；搜索不到字面引用也不能单独作为删除依据。例如教程正文由标题动态转换为“介绍前字”，里程碑文字由原版读取，这些键需要保留。确认废弃后，从词表中移除整条记录。

## 验证范围

静态检查与编译能确认引用、网络字段顺序、词表覆盖和文本格式，实际多人游玩及界面排版仍需游戏内验收。重点检查中途加入、跨星球后再返回、插件装卸与拆除返还、共享设置和乾坤存入、温室联动，以及切换五种语言后重新打开相关窗口。

构建所需的游戏参考库准备和只编译命令见 [开发说明](../README-For%20programmer.md#编译注意事项)。
